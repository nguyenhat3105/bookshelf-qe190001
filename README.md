# BookShelf — QE190001

Flutter/Firebase practical exam submission by Nguyễn Ngọc Như Ngân.

## Firebase setup

1. Create or select a Firebase project.
2. Enable Email/Password in Authentication.
3. Create a Cloud Firestore database and publish `firestore.rules`.
4. Register Android app `com.qe190001.bookshelf_app`.
5. Download `google-services.json` into `android/app/`.
6. Run `flutter pub get`, then `flutter run`.

The release APK can be built with `flutter build apk --release`.
